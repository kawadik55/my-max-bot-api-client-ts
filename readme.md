# Max Bot API Client

Форк [`@maxhub/max-bot-api`](https://github.com/max-messenger/max-bot-api-client-ts) с исправлениями критических багов в long polling.

## Отличия от оригинала

В оригинальной библиотеке есть два бага, из-за которых бот в production ведёт себя непредсказуемо:

**Тихая смерть polling** — при сетевой ошибке бот перестаёт получать обновления, но продолжает работать внешне. Никаких ошибок в консоли нет, никаких признаков проблемы — бот просто молча игнорирует все сообщения пользователей.

**Падение процесса в Node.js 22+** — нативный `fetch` в Node.js 22 бросает `DOMException { name: "TimeoutError" }` при таймауте запроса. Оригинальная библиотека её не перехватывает, поэтому процесс падает с необработанным исключением.

Этот форк исправляет оба бага и добавляет:

- **Exponential backoff** — при сбоях polling повторяет попытки с нарастающей задержкой: 1с → 2с → 4с → 8с → 10с (макс), после восстановления соединения счётчик сбрасывается
- **`bot.isPollingActive()`** — метод для проверки, запущен ли в данный момент long polling
- **`onPollingError` в `bot.start()`** — колбэк для логирования ошибок polling: `(err, retryCount, nextDelayMs) => void`

Публичный API полностью совместим с оригиналом — замена пакета не требует изменений в коде бота.

## Быстрый старт

> Если вы новичок, то можете прочитать [официальную документацию](https://dev.max.ru/), написанную разработчиками Max

### Получение токена
Откройте диалог с [Master Bot](https://max.ru/masterbot), следуйте инструкциям и создайте нового бота. После создания бота Master Bot отправит вам токен.

### Установка
#### npm
```sh
npm install @irklva/max-bot-api
```
#### yarn
```sh
yarn add @irklva/max-bot-api
```
#### pnpm
```sh
pnpm add @irklva/max-bot-api
```

### Пример
```javascript
import { Bot } from '@irklva/max-bot-api';

const bot = new Bot(process.env.BOT_TOKEN);

// Установка подсказок с доступными командами
bot.api.setMyCommands([
  { 
    name: 'ping',
    description: 'Сыграть в пинг-понг'
  },
]);

// Обработчик события запуска бота
bot.on('bot_started', (ctx) => ctx.reply('Привет! Отправь мне команду /ping, чтобы сыграть в пинг-понг'));

// Обработчик команды '/ping'
bot.command('ping', (ctx) => ctx.reply('pong'));

// Обработчик для сообщения с текстом 'hello'
bot.hears('hello', (ctx) => ctx.reply('world'));

// Обработчик для всех остальных входящих сообщений
bot.on('message_created', (ctx) => ctx.reply(ctx.message.body.text));

bot.start();
```

### Обработка ошибок
Если во время обработки события произойдёт ошибка, Bot вызовет метод `bot.handleError`. По умолчанию `bot.handleError` просто завершает работу программы, но вы можете переопределить это поведение, используя `bot.catch`.

> ⚠️ Завершайте работу программы при неизвестных ошибках, иначе бот может зависнуть в состоянии ошибки.

> ℹ️ [`pm2`](https://pm2.keymetrics.io/) может автоматически перезапустить вашего бота, если он остановится по какой-либо причине
